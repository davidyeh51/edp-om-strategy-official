# 太陽能光伏 O&M 維運策略網站

這是一個以高階經理人與客戶閱讀為目標的靜態網站，內容整理自太陽能光伏 O&M 維運策略文件。

## 內容重點

- 四年策略目標：2026-2029 年。
- 營收與利潤：四年總營收 12 億，累計淨利 1.8 億。
- 營運規模：總管理容量 209MW 成長至 868MW。
- 服務組合：M / OM / AM 三層服務與 PR 保證。
- 地理策略：台中以南集中布局。
- 驗證機制：EDP 假設清單與里程碑驗證門。

## 檔案

- `index.html`：網站首頁。
- `styles.css`：企業網站樣式。
- `app.js`：圖表與資料表渲染。
- `strategy-brief.md`：整理後的文字摘要。
- `assets/solar-om-hero.png`：網站主視覺。
