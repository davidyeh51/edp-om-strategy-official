三層服務定義與 Portfolio Mix

M/OM/AM 為服務內容深度分類，與案場規模無綁定。AM 佔比將從 0% 提升至 40%。

層級 服務內容 費率 PR 承諾
M（維護型） 定期巡檢、清洗安排、故障通報與基礎排除、年度報告 20萬/MW/年 PR ≥ 80（參考，不保證）
OM（營運型） M全包 ＋ 遠端監控、預防性維護、妥善率追蹤、月報 35萬/MW/年 PR ≥ 82（保證，未達標提改善計畫）

  • 四年內要從「零實績」建立到「近半數容量」。
  • 依 Q17：AM 不凍結、搶案為主 → 商業驗證與規模化同步進行。
  • 此為本計畫最高風險項。

工程業務模型 (B方案)

決策採用 B方案：拉高單案均值 (39萬 → 200萬/件)。質的躍升，非量的堆疊。

年度 工程收入 目標單案均值 修理工程 整改工程
FY20262,000萬39萬/件556萬1,424萬
FY20273,960萬70萬/件808萬3,152萬
FY20287,920萬130萬/件1,304萬6,616萬
FY20291.58億200萬/件2,180萬1.37億

整改工程三大類型 (主動開發)

  • 案場異常修理：設備故障 (4萬~450萬)，被動。
  • 案場 Retrofit：設備升級、系統現代化 (100~300萬)，主動。
  • 案場整新：設備老化更新 (200~500萬)，主動。

B方案實質內容：從「等異常修理」轉向「主動提案 Retrofit 與整新」。

交叉銷售機制
維運數據分析 → 辨識衰退 → BU 主動提案 → 整新報價
目前此機制不存在，為 FY2027 必須建置的優先事項。

關鍵假設、里程碑與收斂機制

最高優先驗證假設與 Gate 門檻，未達標則啟動 No-Go 機制。

里程碑 Gate 截止 核心行動與 Go 標準 No-Go 處置 (收斂機制)
M1 整改工程機制 2026/Q4 建立商機報價流程，產出首批 ≥5 件提案 工程成長改為保守，FY2027 下修至 2,800萬
M5 AM Scale-up 2027/Q2 建坤自益案完成 12 個月週期驗證，五項全過 新簽 AM 採保守賠償上限，AM 佔比目標下修
M7 交付能力 Gate 2028/Q3 外包率 ≥75%、抽查合格率 ≥90% 停止新增超出交付能力的案件 (第三層止血)
資金單一風險 隨時 95% 資金來自國泰電業，需書面撥付條件 若發生資金抽離，啟動第四層組織收斂

收斂／No-Go 機制 (若營收 < 70%)

優先停止尚未驗證的成長 → 再凍結高風險產品 (AM) → 控制新增交付 → 最後調整既有 M/OM 核心。
核心目的：保護現金流、毛利與既有客戶續約。
